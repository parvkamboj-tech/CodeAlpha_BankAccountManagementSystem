# Bank Account Management System

## Description
A simple Bank Account Management System developed in C language using Structures, Functions, Pointers and File Handling.

## Features
- Create New Account
- Deposit Money
- Withdraw Money
- Balance Enquiry
- Persistent Data Storage using File Handling
- Menu Driven Interface

## Technologies Used
- C Programming
- Structures
- Functions
- Pointers
- File Handling

## How to Run

### Compile
```bash
gcc bank.c -o bank
```

### Run
```bash
./bank
```

## Project Concepts
- Structure
- Functions
- Pointers
- Binary File Handling
- Menu Driven Programming
